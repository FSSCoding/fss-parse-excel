## To Upload a New Document
Navigate to where you would like the document and using the following steps.
1. Find the relevant folder in published documents and click upload.
1. Once the document appears on the page, find the generated Share URL on the righthand side of the document (this may take a few minutes).
1. Copy the share URL and return to the front end of the portal.
1. Find the page where the document will live and create a dot point with the document name, then hyperlink the text using the Share URL.
1. Publish the page.
### If a form/document is being updated
Rename the new file to the same name as the file in ‘Published Documents’,
Upload the file and when asked on the right-hand side, Replace or Keep both, Select Replace.
Do not delete existing file. Follow instructions to delete files
## To Move a File within the ‘Published Documents’ library
To move a document, right click on the 3 dots for the document and then select move to. 
The document should be moved within the ‘Published Documents’ library only. 
## To Delete a File within the ‘Published Documents’ library
Files should not be deleted; they should only be moved to 
A record of all files moved here will be created to keep track of where files are archived from.
